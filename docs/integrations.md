# Отчёты из 1С и CRM

В Docspace есть отдельный раздел **«Отчёты из систем»**: 1С:Предприятие, Битрикс24, amoCRM и другие источники. У каждого источника — список отчётов выбранной команды, поиск, фильтр статусов, загрузка файла, настройки обмена и инструкция. Источник и способ поступления сохраняются в карточке: ручная загрузка, API или демо.

## Для бухгалтера и менеджера

1. Сформируйте отчёт в своей системе. Сохраните PDF, XLSX или CSV. CSV должен быть в UTF-8; поддерживаются запятая, точка с запятой и табуляция. XLS и MXL нужно предварительно сохранить в PDF/XLSX/CSV.
2. Откройте «Отчёты из систем», выберите источник и нажмите «Загрузить отчёт».
3. Выберите команду, канал, файл и срок. Флажок «Сразу отправить руководителю» ставит отчёт на согласование. Доступ к загрузке есть у участников команды.
4. Руководитель скачивает исходный файл, оставляет замечания или согласует. Новую версию можно приложить к той же карточке. При наличии родительской команды согласованный отчёт можно передать выше.

В Битрикс24 экспорт находится в CRM, в режиме списка; для совместимости выбирайте CSV. В amoCRM используйте «Сделки → Ещё → Экспорт → CSV». Доступность конкретной выгрузки определяется правами и возможностями исходной системы. Названия кнопок и экспорт 1С зависят от конфигурации.

## Для разработчика компании

Руководитель открывает «Отчёты из систем → источник → Подключение», выбирает команду и канал и создаёт ключ. Ключ действует в одной команде, хранится на сервере в виде SHA-256 и показывается только при создании. Внешняя система использует заголовок `Authorization: Bearer ...`. При наличии ключа страница показывает «Ожидаем первый файл»; после успешного импорта — «Файлы по API получены». Выпуск ключа сам по себе не подключает 1С или CRM.

### Проверка и выбор канала

`GET /api/integrations/channels` с ключом возвращает только каналы команды этого ключа. Отозванный или неверный ключ получает HTTP 401.

### Отправка файла

`POST /api/integrations/documents` принимает **байты файла** в теле запроса.

| Параметр URL | Назначение |
| --- | --- |
| `channelId` | ID канала команды ключа, обязателен |
| `title` | Название до 180 символов, обязательно |
| `filename` | Имя файла с расширением, обязательно |
| `externalId` | Устойчивый ID отчёта/периода/ревизии; используйте для защиты от повторов |
| `review=1` | Сразу отправить на согласование |
| `description` | Контекст проверки, до 2000 символов |
| `due` | Срок в формате YYYY-MM-DD |

Форматы: PDF, DOCX, XLSX, TXT, CSV, PNG, JPG. Размер: от 1 байта до 25 МБ. Параметры URL кодируются в UTF-8. HTTP 201 возвращает новую карточку; повтор с тем же ключом и externalId возвращает прежнюю карточку с HTTP 200. Повтор не меняет файл: для исправленного отчёта используйте новый внешний ID или загрузите версию через карточку. При `review=1` руководителям ставится уведомление в очередь бота.

### Чтение решения

`GET /api/integrations/documents?externalId=YOUR_ID` с тем же ключом возвращает карточку, в том числе `status`, `revision`, `updated`, `comments`. Статусы: `draft`, `review`, `changes`, `approved`. Замечания руководителя находятся в системных комментариях. Ключ может читать только отчёты, отправленные именно им, даже если другой ключ относится к той же команде. Неизвестный внешний ID — HTTP 404. Отзыв ключа прекращает и импорт, и чтение статусов.

### Готовый HTTP-клиент

В репозитории: `scripts/send-report.py`. На странице подключения его можно скачать. Требуется Python 3.9+, внешних библиотек нет. Скрипт проверяет TLS, запрещает перенаправления запросов с ключом, поддерживает кириллицу в названиях и возвращает ненулевой код при ошибке.

PowerShell (ключ вставляется локально и не включается в исходники):

```powershell
$env:DOCSPACE_INTEGRATION_TOKEN = 'КЛЮЧ_ИЗ_ИНТЕРФЕЙСА'
python scripts/send-report.py --base-url https://YOUR_HOST --channels
python scripts/send-report.py --base-url https://YOUR_HOST --channel CHANNEL_ID --file report.csv --title 'Отчёт за сентябрь' --external-id finance-2026-09-v1 --review
python scripts/send-report.py --base-url https://YOUR_HOST --status finance-2026-09-v1
```

Для локального теста разрешён HTTP только на localhost/127.0.0.1/::1. В рабочем режиме нужен HTTPS. Секрет передаётся через переменную окружения, не через URL или аргумент процесса. В настройках можно скачать JSON без секрета с адресами и выбранным каналом.

### Сторона 1С и CRM

Для 1С приложен `web/public/integration/1c-send-report.bsl`: шаблон серверного вызова POST с двоичным файлом и GET для чтения результата. Он доступен для скачивания из страницы 1С. Разработчик должен сформировать файл средствами своей конфигурации, подготовить URL-кодированные параметры, настроить доверенные сертификаты и права исходящего HTTP, хранение ключа, расписание и повтор запросов. Шаблон не является готовой обработкой EPF и не проверялся в установленной базе 1С; такой базы в рабочей среде нет.

Для CRM можно использовать выгруженный CSV напрямую или сервис компании, который получает данные с разрешениями CRM, формирует файл и вызывает этот протокол. Готовых OAuth-коннекторов, чтения базы 1С и автоматической записи результата в объекты CRM здесь нет. Чтение статуса уже реализовано; обновление объекта исходной системы выполняет адаптер компании.

## Демо и проверенные сценарии

Демо содержит вымышленные ОСВ, ДДС, бюджеты, реестры платежей и CRM-сделки. Кнопка «Демо-выгрузка» создаёт файл без соединения с поставщиком; она есть только в деморежиме и только у руководителя выбранной команды.

Проверены Go-тестами: права на импорт, источники ручных загрузок, изоляция ключей, чтение решения и отзыв доступа. `web/report-workflow-e2e.mjs` запускает настоящий Python HTTP-клиент против отдельного локального сервера, отправляет CSV, проверяет отсутствие дублей, открывает и скачивает файл через мобильный UI, согласует его, читает статус клиентом и проверяет отказ после отзыва ключа. Это проверка протокола Docspace, не проверка подключения к реальной базе 1С или аккаунту CRM.

Официальные источники: [HTTP в 1С](https://v8.1c.ru/platforma/rabota-s-http-i-ftp/), [экспорт Битрикс24](https://helpdesk.bitrix24.ru/open/20966844/), [экспорт amoCRM](https://www.amocrm.ru/support/export/export_leads).
