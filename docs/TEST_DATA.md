## 1. Назначение и свойства данных

Тестовый набор данных обеспечивает воспроизводимую проверку сервиса:
1. Защита персональных данных (Zero PII по 152-ФЗ). В базе данных отсутствуют паспортные данные, номера банковских карт и СНИЛС. Идентификация работает через детерминированный строковый идентификатор max_user_id.
2. Разделение таксономии. Нормативные акты и статьи законов зафиксированы как факты. Налоговые платежи и точка безубыточности рассчитываются по формулам. Советы ассистента выделены в рекомендации. Демонстрационные правила согласовавания вывесок помечены флагом is_mocked_data = TRUE.
3. Детерминированность. Все идентификаторы UUID сгенерированы на основе детерминированных хэшей пространств имен (UUIDv5). Повторный запуск миграций или пайплайна обновляет существующие записи без дублирования.

## 3. Детальное описание краевых сценариев

### Сценарий 9: Самозанятый на пороге лимита дохода (NPD Threshold Warning)
Самозанятый дизайнер интерьеров Алина Зарипова получает 195 000 рублей в месяц.

При умножении на 12 месяцев годовой доход составляет 2 340 000 рублей. Это 97.5% от предельного порога в 2.4 млн рублей, установленного пунктом 8 части 2 статьи 4 Федерального закона № 422-ФЗ.

Реакция системы: в результатах финансового анализа и налогового калькулятора формируется предупреждение:
«ВНИМАНИЕ: Годовой доход приближается к 2.4 млн руб. (порог 97.5%). Подготовьте документы для бесшовного перехода на ИП на УСН 6% без штрафов и блокировки чеков».

### Сценарий 10: Убыточный бизнес и кассовый разрыв (Loss-Making & Cash Gap)
ИП розничной торговли сувенирами Денис Васильев имеет ежемесячную выручку 180 000 рублей при расходах 240 000 рублей (аренда в туристическом центре, зарплата продавца, закупка).

Расчетные показатели:
- Чистый убыток: 60 000 рублей в месяц.
- Маржинальность: минус 33.33%.
- Точка безубыточности: 405 000 рублей в месяц (бизнес покрывает лишь 44% необходимых расходов).
- Запас финансовой прочности: минус 125%.

Реакция системы:
- Уровень риска: cash_gap_risk_level = 'HIGH'.
- Вердикт: verdict = 'CRITICAL'.
- Рекомендации: аудит постоянных затрат (снижение аренды на 25%), пересмотр отпускных цен в каталоге MAX и запуск акций с высокой маржинальностью.

## 5. Методология финансовых и налоговых расчетов

### 5.1. Налоговый расчет (актуальность 2026 года)
НПД (Налог на профессиональный доход): ставка 4% при реализации товаров и услуг физическим лицам. Доступен только для self_employed при годовом доходе до 2 400 000 рублей и нулевом штате сотрудников.

УСН «Доходы» (6%): базовая ставка 6%. По статье 346.21 НК РФ:
- ИП без сотрудников уменьшает налог на 100% суммы фиксированных страховых взносов (53 658 рублей за 2026 год).
- ИП и организации с сотрудниками уменьшают налог не более чем на 50%.

УСН «Доходы минус Расходы»: налоговая база равна доходам за вычетом расходов. Применены региональные ставки:
- Республика Татарстан (код 16): 7% по Закону РТ № 44-ЗРТ.
- Свердловская область (код 66): 7% по Закону СО № 31-ОЗ.
- Москва (код 77): 10% для обрабатывающих производств и науки по Закону г. Москвы № 51.
- Базовая ставка по стране: 15%.

### 5.2. Unit-экономика и пороги жизнеспособности бизнеса
1. Маржинальность бизнеса: Margin (%) = (Net Monthly Profit / Monthly Revenue) * 100%.
2. Коэффициент маржинального дохода: CMR = (Monthly Revenue - Monthly Variable Costs) / Monthly Revenue.
3. Точка безубыточности: BEP = Monthly Fixed Costs / CMR.
4. Запас финансовой прочности: SM = ((Monthly Revenue - BEP) / Monthly Revenue) * 100%.
5. Шкала классификации устойчивости:
   - SUSTAINABLE (Низкий риск): SM >= 25% и чистая прибыль > 0.
   - AT_RISK (Умеренный риск): 0% <= SM < 25%. Высокая чувствительность к кассовым разрывам.
   - CRITICAL (Высокий риск): SM < 0% либо чистая прибыль <= 0. Бизнес работает в убыток.

## 6. Проверочные SQL-запросы для DBeaver и psql

### Запрос 1: Аудит профилей, систем налогообложения и витрин
```sql
SELECT 
    bp.business_name,
    bp.legal_form,
    bp.tax_regime_code,
    r.name AS region_name,
    bp.monthly_revenue_est AS revenue,
    s.title AS store_title,
    s.slug AS store_url,
    (SELECT COUNT(*) FROM products p WHERE p.store_id = s.id) AS products_count
FROM business_profiles bp
JOIN regions r ON bp.region_code = r.code
JOIN stores s ON s.business_profile_id = bp.id
ORDER BY bp.monthly_revenue_est DESC;
```

### Запрос 2: Проверка товаров с обязательной маркировкой «Честный ЗНАК»
```sql
SELECT 
    s.title AS store_name,
    p.name AS product_name,
    p.price,
    p.unit,
    p.requires_marking,
    p.is_in_stock
FROM products p
JOIN stores s ON p.store_id = s.id
WHERE p.requires_marking = TRUE;
```

### Запрос 3: Сравнение налоговой нагрузки (НПД vs УСН 6% vs УСН 15%)
```sql
SELECT 
    bp.business_name,
    tc.recommended_regime_code AS optimal_regime,
    tc.estimated_annual_tax AS calculated_annual_tax,
    tc.estimated_annual_insurance AS insurance_contribs,
    tc.results_comparison->'npd'->>'annual_tax' AS tax_if_npd,
    tc.results_comparison->'usn_income'->>'annual_tax' AS tax_if_usn6,
    tc.results_comparison->'usn_income_expense'->>'annual_tax' AS tax_if_usn15
FROM tax_calculations tc
JOIN business_profiles bp ON tc.business_profile_id = bp.id
ORDER BY tc.estimated_annual_tax DESC;
```

### Запрос 4: Анализ финансовой устойчивости, точек безубыточности и вердиктов
```sql
SELECT 
    bp.business_name,
    fha.monthly_revenue,
    fha.net_monthly_profit,
    fha.margin_percent,
    fha.break_even_point,
    fha.safety_margin_percent,
    fha.cash_gap_risk_level,
    fha.verdict,
    fha.recommendations->0 AS top_recommendation
FROM financial_health_assessments fha
JOIN business_profiles bp ON fha.business_profile_id = bp.id
ORDER BY fha.safety_margin_percent ASC;
```

### Запрос 5: Проверка прогресса прохождения регистрационных чек-листов
```sql
SELECT 
    bp.business_name,
    ci.title AS task_title,
    ci.is_mandatory,
    ucp.is_completed
FROM user_checklist_progress ucp
JOIN business_profiles bp ON ucp.business_profile_id = bp.id
JOIN checklist_items ci ON ucp.checklist_item_id = ci.id
ORDER BY bp.business_name, ci.sort_order;
```
